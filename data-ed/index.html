Compatibility notes

Output format: Base64 of the 12-byte IV followed by AES-GCM ciphertext and its 16-byte authentication tag. Encoding creates a fresh random IV each time, so the same JSON will not produce identical output on every run.

This matches your reference for ASCII IDs. Your reference applies btoa() and then atob() to the key, which cancel each other out for ASCII. Non-ASCII IDs may behave differently. Use HTTPS or localhost because Web Crypto requires a secure context in most browsers.
